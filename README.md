Это мини-калькулятор. Пользователь вводит два числа и номер операции. Программа выполняет сложение, вычитание, умножение или деление. При делении программа отдельно проверяет второе введенное число: оно должно быть не нулевым
В ходе этой работы я научился пользоваться switch, break, default и вложенным if.
